## 4. 关键实测证据

### 4.1 自动登录（真实）
- `POST /accounts/main/login` → `{"state":"online","loggedIn":true,"jwtExpiresAt":"2026-11-20T17:06:40.000Z"}`
- 浏览器：CloakBrowser headful 打开登录页 → 勾选协议 → 填写手机号/密码 → humanized 拖动阿里云滑块（一次通过）→ 捕获 `/sso/login` 200 → 提取 JWT → 落库（明文 v1 简化，加密待加固）。
- JWT 7 天；会话失效可重登（滑块由 worker 自动处理，失败会标记 needHuman）。

### 4.2 话单同步（真实）
- `POST /sync {"mode":"full"}` → `{fetched:4105, upserted:3032, failed:0}`；`GET /calls` total=4106（含本地拨测记录）。
- 记录格式（实测）：`audio_assets.sample_rate=8000, channels=2, size=481964`（15.06s 通话）。
- 录音直连下载成功（HTTPS 代理优先），sha256 归档；`audio/{yyyy}/{mm}/{dd}/{callId}.wav`。

### 4.3 转写（真实）
- `GET /calls/call_01M7AY1KDSZDGAWY3HCPBR5ECP/transcript`：
  - `source=asr`, `provider=minimax:asr-1.0`
  - segments: `channel=0 role=agent` / `channel=1 role=customer`（双声道拆分直接得到说话人）
  - `fullText` 已做词表归一
- 长通话（>480s）分块逻辑与断点续跑由单测覆盖（合成 WAV），真实长通话待回填样本验证。

### 4.4 AI 后处理（真实）
- `GET /calls/{id}/detail?includeAnalysis=true` → `analysisPayload`：
  - `summary.short`: “坐席回拨推销客户管理系统，客户明确表示不用并致谢，通话约15秒结束。”
  - `intent.label`: `无意向`；`model=deepseek-chat`；`promptVersion=analysis-v1`
- 失败升级链（flash→附校验错误→v4-pro）与 JSON schema 校验由单测覆盖；真实调用走 flash 成功。
- 回填期间 analysis ready 快速增长（初稿时 102 通，持续增加）。
